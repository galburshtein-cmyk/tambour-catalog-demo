# אפשרויות לשיפור ניווט קטלוג מוצרים – טמבור

דמו אינטראקטיבי להשוואה בין אפשרויות לתצוגת הסינון בקטלוג המוצרים של tambour.co.il (דסקטופ ומובייל).
את האפשרויות מחליפים בסרגל שבתחתית המסך:

- **0 · האתר כמו שהוא היום** – האתר החי, בלי שינוי (דורש אינטרנט).
- **1 · disable** – פאנל סינון אחד, קבוצות שתלויות זו בזו ומאופרות עד שבוחרים את הרמה שמעליהן.
- **2 · פעיל וסגור** – כל הקבוצות פעילות אך סגורות; בחירה ברמה פנימית בוחרת ומציגה את הרמות שמעליה.
- **3 · הכל פתוח ובלתי תלוי** – כל הקבוצות פתוחות, ובחירה ברמה פנימית בוחרת את הרמות שמעליה.

בנוסף: תפריט הניווט העליון פעיל (קישורי קטלוג מפעילים את הסינון המתאים), ומעברים עדינים בהוספה והסרה של סינונים.
התוכן והתמונות של המוצרים שייכים לטמבור. תוכן הקידום להמחשה בלבד.
