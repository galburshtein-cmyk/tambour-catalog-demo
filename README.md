# הדמיית קטלוג מוצרים טמבור

הדמיה אינטראקטיבית של שיפור חוויית הקטלוג באתר tambour.co.il (דסקטופ ומובייל).

- `index.html` – הגרסה הנוכחית: פאנל סינון אחד, כרטיס סדרת מאסטר, טקסטי קטגוריה, כפתור "טען עוד".
- `previous-version.html` – הגרסה הקודמת (תפריט עולמות ואקורדיון + סינון מתקדם נפרד).

ההדמיה בנויה על הדף החי של האתר, ונתוני המוצרים והתמונות הם מהאתר. תוכן הקידום (סדרת מאסטר) להמחשה בלבד.
